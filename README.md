# Incident Management System

A centralized web platform developed during my Software Developer internship at **Attawfiq Microfinance** for monitoring and managing technical incidents across the company's nationwide network of agencies throughout Morocco.

## Features

* Incident creation, tracking, and management
* Agency and network monitoring
* Automated connectivity checks
* Dashboard with statistics and KPIs
* Incident history and filtering
* PDF and Excel report generation
* User authentication and access control

## Technologies

**Backend:** Python, Django, Django REST Framework
**Frontend:** React, Vite, Tailwind CSS
**Database:** MySQL / MariaDB
**Other:** JWT, APScheduler, pandas, ReportLab, openpyxl

## Project Overview

The **Incident Management System** is a centralized web application developed during my Software Developer internship at **Attawfiq Microfinance** to monitor and manage network incidents across the company's agencies throughout Morocco.

The platform allows the IT team to monitor agency connectivity, manage and track network incidents, view statistics through a dashboard, and generate PDF or Excel reports.

A key feature is the **automatic network monitoring system**. It regularly checks agencies affected by an incident and automatically detects when their connection is restored. To avoid false resolutions, the system confirms the connection through multiple consecutive successful checks before closing the incident.

The platform replaces manual monitoring and scattered spreadsheets with a **centralized, automated, and easy-to-use system**, helping the IT team identify and resolve network issues more efficiently.
